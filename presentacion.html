ALCALDÍA DE DURANIA · TURISMO MUNICIPAL

¿Qué se construyó?

Un sitio web de turismo completo y profesional para el municipio de Durania

Diseñado para posicionar a Durania digitalmente, atraer visitantes nacionales e internacionales, y comunicar toda su riqueza turística — desde el apiturismo hasta el inmobiliario rural — en dos idiomas y con una experiencia visual de primer nivel.

🌿 Naturaleza 🍽️ Gastronomía 🐝 Apiturismo 🌾 Agricultura 🏛️ Cultura 🎉 Ferias 🏡 Hospedaje 🏘️ Inmobiliario

Tecnologías Utilizadas

⚛️
React 18
Componentes reutilizables. Estado reactivo. Ecosistema maduro y documentado.
⚡
Vite 5
Bundler ultrarrápido. Servidor de desarrollo en <1 segundo. Hot reload instantáneo.
🎨
Tailwind CSS 3
Utilidades CSS directamente en el HTML. Diseño consistente sin saltar entre archivos.
🌐
i18next + react-i18next
Estándar de internacionalización. Cambio de idioma instantáneo sin recargar la página.
🔗
React Router DOM
Navegación SPA. Rutas limpias. Scroll suave entre secciones con anclas (#id).
✦
Lucide React
1000+ iconos SVG. Ligeros (tree-shakeable). Consistentes en todo el diseño.

Arquitectura del proyecto

Estructura de Componentes

📁 src/
├── main.jsx — Punto de entrada React
├── App.jsx — Raíz, ensambla secciones
├── i18n.js — Config de idiomas
├── index.css — Estilos + animaciones
├── 📁 locales/ es.json · en.json
└── 📁 components/
├── Navbar · Hero · Stats
├── Nature · Gastronomy · Apiculture
├── Agriculture · Culture · Events
├── Lodging · RealEstate · Contact
└── Footer
🔄 Flujo de datos
main.jsx → inicializa i18n y BrowserRouter → monta App → cada componente lee traducciones con useTranslation()
🌐 Internacionalización
El Navbar llama i18n.changeLanguage() → todos los componentes se re-renderizan instantáneamente con el nuevo idioma
🎨 Estilos
Tailwind utilities en JSX + clases personalizadas en index.css (glass, glow, card-hover, animate-*)
📦 Build
Vite compila todo en /dist — 3 segundos. Output: 263KB JS + 33KB CSS (gzip: 85KB + 7KB)

Impacto municipal

¿Por qué es vital para Durania?

1
Visibilidad digitalDurania carecía de presencia web turística. Este sitio la coloca en el mapa digital global, alcanzando turistas que buscan destinos en Norte de Santander.
2
Alcance internacionalEl inglés abre puertas a birdwatchers extranjeros (Colombia: 1° en especies de aves del mundo), investigadores y comunidades en el exterior.
3
Diversificación económicaPromueve fuentes más allá del café: apiturismo, agroturismo, hospedaje rural e inmobiliario — distribuyendo el beneficio entre más familias.
4
Preservación culturalDocumenta digitalmente la historia Chitarera, tradiciones, platos típicos y ferias. Archivo cultural vivo accesible para las nuevas generaciones.
5
Posicionamiento del apiturismoDurania tiene uno de los pocos programas activos de apiturismo en NS. El sitio lo posiciona con precios, descripción y contacto directo.
6
Atracción de inversión ruralLa sección inmobiliaria conecta compradores de fincas y lotes con oportunidades reales del municipio, generando ingresos para propietarios locales.
